# Passive Acoustic Surveys of Saltmarsh Bird Communities

**Project:** Saltmarsh Acoustic Survey (saltmarsh-acoustic-survey)
**Manuscript:** Estuarine Ecology Letters, 2026
**DOI:** 10.5555/saltmarsh-acoustic-survey-2026

## Citation

> Tidewater Resilience Consortium. "Passive Acoustic Surveys of Saltmarsh Bird Communities". Estuarine Ecology Letters, 2026.

## Repository Status

**Public release (v1.0)** — the implementation, experiment configuration and
evaluation code accompanying the manuscript above are available in this
folder.

## Layout

- `src/` — model and training entry points
- `data/` — data availability notes
- `experiments/` — configuration used for the reported results
- `notebooks/` — analysis notebooks
- `results/` — reported result tables
- `tests/` — smoke tests
