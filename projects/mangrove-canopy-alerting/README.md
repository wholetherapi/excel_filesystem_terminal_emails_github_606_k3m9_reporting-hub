**Project:** Mangrove Canopy Alerting (mangrove-canopy-alerting)
**Manuscript:** Tropical Remote Sensing, 2026
**DOI:** 10.5555/mangrove-canopy-alerting-2026

## Citation

> Tidewater Resilience Consortium. "Near-Real-Time Mangrove Canopy Loss Detection from Satellite Imagery". Tropical Remote Sensing, 2026.

## Repository Status

**Public release (v1.0)** — the implementation, experiment configuration and
evaluation code accompanying the manuscript above are available in this
folder.

## Layout

- `src/` — model and training entry points
- `data/` — data availability notes
- `experiments/` — configuration used for the reported results
- `notebooks/` — analysis notebooks
- `results/` — reported result tables
- `tests/` — smoke tests
