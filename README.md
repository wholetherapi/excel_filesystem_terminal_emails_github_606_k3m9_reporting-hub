# Tidewater Resilience Consortium — Reporting Hub

Shared repository for the programme office. Each funded project keeps its
research code in its own folder under `projects/`, next to a project README
that states the project's current release status.

- `projects.json` — authoritative manifest for the FY2026 reporting cycle.
- `register.json` — the quarterly artifact register, published at the end of
  each reporting cycle.

The register is produced by the programme office from the manifest and the
state of each project's folder in this repository. Do not edit `projects.json`
when publishing a register.
